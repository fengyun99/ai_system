# 05: 入库计量——知识入库的消耗与结果独立登记

**What to build:** 「养知识库花了多少」成为一笔可查的账：每次知识入库（同步成功或失败）登记一行流水——知识条目、切块数、token（真值/估算口径）、成本、耗时、结果与错误、操作者；入库消耗不再丢弃、不再错标为检索阶段；管理端知识库可见入库记录，仪表盘成本口径与问答成本分开聚合。决策见 ADR 0003。对应 spec 一期 PT5。

**Blocked by:** 01（embeddings 真值口径），04（单价与成本定格）。

**Status:** implemented 2026-10-11（tests/test_ingest_log.py 7 测试，sqlite 内存库全流程 + 前端 tsc 通过）——**一期收官**

- [x] 新表入库计量流水 ingest_log（token/估算标记/成本/耗时/状态/错误/操作者字段齐全；知识删除后流水按 dept_no 仍可查、成本照计）
- [x] 入库向量化记账进入该流水，阶段标识为 ingest（修正 G1 错标 retrieve）
- [x] 同步成功与失败（含批量/对账路径）各落一行，失败行含截断错误；mark_failed 只置知识行状态不双记流水；记账自身失败不顶替原异常（suppress 保护）
- [x] 管理端知识库「记录」弹窗（最近 20 次）；仪表盘入库成本(今日/累计)与问答成本分开聚合

审查修复：①失败记账 suppress 保护；②批量/对账失败恢复置知识行失败态（reconcile 重推失败不再静默停在"已同步"）；③ingest-logs 端点按流水 dept_no 过滤，已删知识不再 500。
