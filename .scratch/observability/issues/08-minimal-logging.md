# 08: 日志最小落地——审计流水与日志同键可互查

**What to build:** 启用结构化应用日志并绑定轮次/溯源上下文：每个请求一行访问日志；RAG 管线与 LLM 网关的关键路径（阶段起止、模型调用成败）输出携带轮次号与 TraceId 的日志；按天轮转、限定保留期。达成「任取一轮次号即可在日志中还原该轮全部调用与异常」。对应 spec 二期 ST3。

**Blocked by:** None (can start immediately)（属二期；TraceId 全入口由 03 提供，未完成时仅记录轮次号亦可工作）。

**Status:** ready-for-agent

- [ ] 结构化日志落地（时间/级别/轮次号/TraceId/阶段/消息），按天轮转、保留 14 天
- [ ] 请求中间件：访问日志一行一条（方法/路径/状态/耗时/轮次号），上下文请求级置入与清理
- [ ] 阶段登记与 LLM 网关调用（开始/结束/失败）输出绑定上下文的日志
