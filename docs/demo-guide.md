### 4. 业务流程办理（核心演示）——对齐真实线上流程

问 `我要办理租房提取` → 点 **▶ 租房提取办理**。流程 12 节点按福州真实线上办理动线编排（缴存资格核验 → 婚姻声明 → 无房联网核验 → 租赁信息 → **材料上传** → 备案核验 → 收款账户 → 确认 → 自动受理）：

| 步骤 | 操作 | 演示点 |
|---|---|---|
| 自动·缴存资格 | 发起后系统自动执行 | **对接缴存登记系统**：连续缴存月数核验（≥3 个月） |
| 1. 婚姻状况 | 选"已婚"但**不填配偶**提交 | ⚠️ 联动校验："已婚家庭办理需填写配偶姓名/身份证号"（额度按家庭、房产按家庭核验） |
| 自动·无房核验 | 补齐配偶信息后系统执行 | **对接不动产登记中心**：本人+配偶名下无自有住房（数据联网核查免交纸质证明） |
| 2. 租赁信息 | 租赁类型/月租金/提取频次/提取金额 | 金额额度校验 |
| 3. 材料上传 | **先直接点下一步** | ⚠️ "请上传「租赁合同（备案凭证）」"必传拦截 |
| 3. 材料上传 | 📎 选择一份租赁合同 PDF/图片 | 上传接口（jpg/png/pdf ≤10MB）→ 绿色已传状态（文件名+大小） |
| 自动·备案核验 | 上传后系统执行 | **对接住建租赁备案系统**：合同要素与备案信息比对 |
| 4. 收款账户 | 故意填 `1234` / 他人卡 `6228480402564890018` | 两层校验拦截（格式/非本人登记卡），**停留原节点** |
| 4. 收款账户 | 填本人登记卡 `6222021234567890123` | 通过 → 确认页（婚姻/租赁/金额/材料/脱敏卡号全摘要） |
| 确认提交 | 点确认 | 账户核验→额度校验→受理 **自动链** → **受理单号 SL…** |
| 历史还原 | 切走会话再切回 / 刷新 | 终态三段式完整重建：办理信息**含材料清单（文件名+大小）**、失败尝试留痕、受理结果 |
| 取消 | 再发起一次，点取消流程 | 门控解除恢复问答 |

> ⚠️ 卡号校验按**登录账号**绑定身份匹配：admin 用 `6228480402564890018`、fzzx 用 `6222021234567890123`，别用混。

### 7. 管理端——admin（全量）/ fzzx（本部门及以下）

- **仪表盘**：会话/轮次/Token 出入/首字延迟/耗时 + 意图与主题分布（数据实时）
- **轮次审计**：任意轮次详情 → 9 个阶段流水（每阶段模型名/token/耗时，检索阶段可见 qwen3.7-text-embedding）
- **知识库**：新增一条（如"省直公积金缴存比例"挂 35001）→ 保存即向量化入库 → 回门户提问立即命中；"批量同步"可演示失败自愈
- **权限差异**：fzzx 看不到菜单管理页、用户列表仅本机构及以下；qzzx 无管理端入口
- **流程配置（业务配置 → 流程定义/流程实例）**：
  - 打开租房提取的编辑器：12 节点真实流程可视化（节点行编辑：类型/标题/动作下拉；表单字段/材料槽行内增删；JSON 高级模式双向切换）
  - 改一个节点标题 → **保存草稿** → 列表出现"已发布·有草稿改动"标记；回门户发起办理仍是旧标题（草稿不影响线上）
  - 点**发布** → 再发起办理即用新标题（发布即时生效）；办理中的实例不受影响（定义快照）
  - 制造一个坏草稿（JSON 模式删掉 end 节点）→ 发布被拦："发布校验未通过：缺少 end 节点"
  - 流程实例页：查看在途/历史实例轨迹（每步结果时间线），对卡住的办理点**强制取消**（该会话问答门控即时解除）

### 8. 开放接口（外部系统视角）——curl / Postman

```bash
curl -X POST http://127.0.0.1:9310/api/open/v1/chat/ask \
  -H "X-API-Key: sk-open-demo0123456789abcdef0123456789" \
  -H "X-Source-System: erp-demo" -H "X-Trace-Id: demo-001" \
  -H "Content-Type: application/json" \
  -d '{"question":"福州公积金贷款最高能贷多少","id_card":"350105199503031236"}'
```

| 演示点 | 说明 |
|---|---|
| 三要素外部注入 | 传测试甲证件号 → 回答返回**测试甲**的账户数据（188,000 元） |
| 跨租户区域路由 | 35001 接入方问福州/泉州 → 自动路由对应租户知识 |
| 溯源 | X-Trace-Id 回显响应头；`GET /api/open/v1/turns?trace_id=...` 反查轮次 |
| 安全边界 | 无 Key 401 / 越权续会话 404 / 三要素格式错 422 |
