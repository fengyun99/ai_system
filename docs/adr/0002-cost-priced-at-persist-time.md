# 成本按登记时单价定格落库（不查询时重算）

token 消耗已随轮次/阶段流水登记（turn_stage），要不要折算金额、何时折算：决定在
`_persist` 落库时按当时的模型单价（model-config.json）算好 cost 定格进
turn / turn_stage / 入库计量流水，而不是查询时按现价实时换算。理由：这些表是审计
流水，审计的生命线是口径不可变——同一轮次昨天看和今天看金额必须一致；"按新单价
重估历史"属于报表分析场景，可在查询时另行计算，落库值必须定格。

## 后果

- 调价后历史金额不更新（预期行为，不是 bug）。
- 单价配置缺失的模型条目 cost 记 0；金额始终可由 token 数 × 现价补算，不丢信息。
- 单价属于配置而非数据：改价 = 改 model-config.json，生效于之后的登记。

## 备选方案（已否）

- 查询时实时换算——单价可热更新、不占存储，但审计口径随调价漂移，轮次成本不可
  复现；且每一处展示/导出/接口都要重复实现换算逻辑。
